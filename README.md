# 스트리머 게임 시리즈 상점

스트리머 게임 시리즈의 공통 굿즈 카탈로그를 보여주는 정적 웹사이트입니다. 첫 카테고리는 오리지널 스티커입니다.

## 현재 화면

- 첫 오리지널 스티커 팩 8종 미리보기
- 반응형 상품 카드와 상세 미리보기 대화상자
- 가격과 판매 일정이 정해지기 전까지 구매 버튼 대신 미리보기만 제공

## 상품 데이터

상품 카탈로그는 `catalog/stickers.json`에 있습니다. 이 파일과 이미지 자산은 GitHub 저장소와 Pages에서 공개적으로 열람·다운로드할 수 있으므로 공개 가능한 상품 정보만 넣습니다. 상품 또는 아트워크를 바꾸면 GitHub Pages를 다시 배포해야 합니다.

첫 시안은 `assets/sticker-pack-01.png`의 투명 스프라이트 시트를 사용합니다. 스티커 셀의 위치와 문구는 JSON에서 관리합니다.

## 로컬 미리보기

저장소 루트에서 다음 명령으로 정적 페이지를 열 수 있습니다.

```sh
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 배포

`.github/workflows/pages.yml`이 `main`에 push되면 GitHub Pages를 배포합니다. 워크플로는 웹페이지, 카탈로그 JSON, 이미지 에셋만 배포합니다.

구매·소유권 기능을 연결할 때는 Firebase Authentication의 공통 UID와 Cloud Functions를 사용하고, 가격·결제 검증과 소유권 기록을 서버에서 처리합니다. 이 프로토타입에는 결제나 소유권 기록 기능이 포함되어 있지 않습니다.
